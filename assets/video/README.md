| File | Where it plays |
| --- | --- |

| `slot-01.mp4` | From the air — Coast and horizon (large left card) |
| `slot-02.mp4` | From the air — Accra from above |
| `slot-03.mp4` | From the air — Swiss ridgelines |
| `slot-04.mp4` | From the air — Green country |
| `slot-05.mp4` | From the air — On the ground |

Suggested export: H.264 MP4, 1920×1080, under ~20 MB each so GitHub Pages stays snappy. Keep a still poster in `assets/images/` if you also want a fallback thumbnail.
