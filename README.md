# Polley-Consulting

Samuel Polley's personal website is in [`Samuel-Polley-Website-GitHub/`](./Samuel-Polley-Website-GitHub/).

**Live site (after GitHub Pages is enabled):** https://yevucee.github.io/Polley-Consulting/

```bash
cd Samuel-Polley-Website-GitHub
npm ci
npm run dev          # local preview
npm run build:pages  # static export for GitHub Pages
```

Enable **Settings → Pages → Source: GitHub Actions** on the repository, then push to `main`.

See the folder README for footage notes, tests, and optional Cloudflare deployment.
